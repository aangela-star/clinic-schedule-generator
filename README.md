\# 同仁可用的網頁版門診表產生器



此專案是純前端（HTML/CSS/JavaScript）工具，打開 `index.html` 後即可：



\- 直接在網頁輸入或修改資料（不需改 JSON、不需改程式碼）

\- 即時預覽固定 1080 x 1920 的雙院區門診海報

\- 一鍵匯出 PNG（使用 html2canvas）



\## 檔案結構



\- `index.html`：頁面結構與輸入/預覽區

\- `style.css`：版面與海報樣式

\- `app.js`：資料模型、即時渲染、PNG 匯出邏輯

\- `README.md`：使用說明



\## 使用方式



1\. 下載或 clone 專案。

2\. 用瀏覽器開啟 `index.html`。

3\. 在「資料輸入區」修改：

&#x20;  - 標題

&#x20;  - 兩家診所名稱

&#x20;  - 每個時段對應醫師或文字（如輪班、停診）

&#x20;  - 本週門診異動（多行）

&#x20;  - 備註（多行）

4\. 右側/下方會即時更新海報預覽。

5\. 點選「產生圖片 / 下載 PNG」即可下載。



\## 部署到 GitHub Pages



此專案無後端，直接將這四個檔案放到 repository 根目錄即可部署。
